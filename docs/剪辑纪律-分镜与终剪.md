## 1. 分镜阶段纪律（写进 LLM 提示词，逐条可判定）

1. **字幕断句优先于行文好看**：旁白长句必须用逗号/句号主动断开，**单句 ≤18 字**（= 引擎 `generate_srt.py --max-chars` 默认值）。
   一句 40 字的文案，词级对齐也只能给你切出两条 20 字的尴尬字幕 —— 断句在**写**的时候最便宜，在**切**的时候最贵。
2. **时间只用浮点秒，保留 2~3 位小数**：`duration_sec_estimate` / `real_clip.start_sec` 一律秒。
   **禁止** `HH:MM:SS`、禁止帧号 —— 两种单位在微秒换算时必然错位。
3. **抽象风格要拆成可执行要素**：用户说"赛博朋克风"不算需求。落成镜头语言六字段 + 节奏 + 字幕倍率
   （冷调 / 硬光 / 特写 / 缓推 / `subtitle_scale` 高），否则下游只是抄了个词。
4. **实拍镜把话让给原声**：`visual.real_clip` 的镜头，`audio.text` 写画面意图而非朗诵腔解说；
   情绪爆发和原声对白不要盖旁白（引擎 A4 已把原生音轨接进线并做 ducking）。
5. **动效名只能用本机枚举里的原文**：转场/文字动画取自本机 `pyJianYingDraft`
   （`TransitionType` 453 个、`TextIntro` 145 个）。**不许造名字、不许抄外部 ID**；
   引擎 `_resolve_enum`（`generate_draft.py:18`）匹配不上时的行为是「该项不加 + stderr 告警」，
   草稿照样生成、照样能打开 —— 也就是说写错的名字**只掉在日志里，不掉在报错上**。
   已实测可用的短视频常用档（本文档是唯一名单来源，提示词引用它）：
   - 转场：`叠化`（默认）、`闪黑`、`闪白`、`模糊`、`横向滑动`、`推近`
   - 字幕入场：`渐显`（默认）、`弹入`、`打字机_I`、`向上滑动`
   - 反例（**本机不存在**，凭直觉写上去等于没写）：`横移`、`竖移`、`缩放`、`渐隐`、`开合`

   沙箱实测（A3 验收）：`闪黑` → `materials.transitions` 落 2 条、名称正确；
   `横移` → 0 条且只打印告警。两者草稿文件都"看起来正常"，差别只在动效没了。

## 2. 字幕层纪律

- **`transform_y` 三个档位**：字幕 ≈ -0.8、居中标题 ≈ 0.0、顶部标题 ≈ 0.8。
  我方账号默认 `-0.55`（`storyboard_schema.py:39`，用户反馈 -0.7 太靠下后上调），改数值要过用户眼验。
- **同轨不得时间重叠**：两条文本在同一时刻重叠，剪映会糊成一块。要么分轨，要么错开时间。
  旁白字幕走 `import_srt` 单轨，靠的就是 A1 的逐句切分保证不重叠；**另加标题/关键词层时必须换轨**。
- **入场动画时长 ≤ 该文本段时长的 1/3**（引擎 `apply_transition` 同一条 `span=min(want, dur/3)` 规则）：
  0.7s 的字幕配 0.5s 渐显，观众看到的是"一直在淡入"。
- **花字与动画二选一**：要"风格化字形"就配色/描边（样式），要"动"就入场动画。同一段文本叠加两套，
  剪映渲染会互相盖掉。

## 3. 画布与素材纪律

- **比例只能在创建草稿时定死**，事后改比例必带黑边 —— 引擎 `generate_draft.py:175-183` 在
  `create_draft(width, height)` 之前解析 `aspect_ratio`，就是这个原因；未内置比例回退 9:16 并明确告警。
- **素材一律绝对路径**（`~` 要先展开）。
- **BGM 必须在音频轨**，不能出现在视频轨（验收要查这一条）。
- **长素材喂 AI 分析前先压**：≤30 分钟、优先 360p。混剪挑片段时尤其重要 —— 原文件直传既慢又会被截断。

## 4. 草稿验收清单（引擎跑完后 agent 自检，逐条可验证）

对应它 `agent-playbook.md` 的 Mandatory Acceptance Checklist，翻译成我方口径：

1. 草稿目录存在于剪映 `Drafts/` 下，且 `save()` 成功（明文 JSON 已落盘）。
2. 视频轨至少 1 个 segment（空草稿是最常见的静默失败）。
3. 有 BGM → 它在**音频轨**，不在视频轨。
4. 有旁白 → 有字幕段，且字幕总时长与音频轴一致（不是"条数等于镜数"：A1 起长镜按词边界拆逐句，条数**多于**镜数是正常的，见 `qc_checks.py:298`）。
5. 每个 `draft_ready` 任务都真的产出了草稿文件 —— 状态与产物一致才算过。

**机器断言路径**（Mac 11.4.2 补丁会把 `draft_content.json` 重命名成 `draft_info.json`，别按前者找）：

| 断言 | JSON 路径 |
| :-- | :-- |
| 视频段存在 | `tracks[].segments[]`（`materials.videos` 有素材 ≠ 上了轨） |
| Ken Burns 生效 | `tracks[].segments[].common_keyframes[].keyframe_list[]`（**不在** `materials` 下） |
| 镜间转场 | `materials.transitions[]`，按 `name` 比对名单 |
| 字幕入场动画 | `materials.material_animations[].animations[]`（`import_srt` 建的段要手动登记，见 `generate_draft.py:69`） |
| 画布比例 | 创建日志行 `画布 WxH`，或 `materials.canvases` |

## 5. 人工终剪清单（交给用户，Mac 侧无法目检的部分）

引擎在 Mac 上只能保证**草稿结构正确**，渲染观感必须人眼过一遍：

- [ ] 打开草稿不报"资源缺失"，画布比例正确无黑边
- [ ] Ken Burns 运镜与叠化不越界（缩放回 1.0 时横移应归 0）
- [ ] 字幕逐句出现、与配音对得上，未被画面主体遮挡
- [ ] 实拍镜原声在、旁白不压对白
- [ ] 观感不对 → `--no-polish` 重出裸草稿对比，定位是动效还是内容问题
